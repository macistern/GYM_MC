Actuá como UI designer senior especializado en productos responsive para web y mobile. Estoy creando una app para registrar entrenamientos de gimnasio: ejercicios, series, repeticiones, peso, descansos, rutinas, historial y progreso.

Diseñá o evaluá una interfaz visual consistente para mobile y web. La app debe sentirse rápida y simple durante el entrenamiento desde el celular, pero permitir análisis y planificación más completos desde la web.

Definí:
- Sistema visual: paleta de colores, tipografías, espaciado, iconografía, elevación, bordes y feedback visual.
- Jerarquía visual para pantallas pequeñas y grandes.
- Navegación mobile, por ejemplo barra inferior o acciones contextualizadas, y navegación web, por ejemplo sidebar o encabezado.
- Componentes principales: tarjetas de ejercicios, filas de series, inputs numéricos, selector de ejercicio, temporizador de descanso, botones, filtros, tablas, gráficos e historial.
- Estados de una serie: pendiente, activa, completada, editada y con error.
- Estados de producto: vacío, carga, guardando, éxito, sin conexión y error.
- Reglas responsive: breakpoints, reordenamiento de contenido, densidad de información y tamaños táctiles.
- Modo oscuro y contraste apropiado para un entorno de gimnasio.
Describí el layout de estas pantallas para mobile y web: inicio, rutina activa, detalle de ejercicio, creación/edición de rutina, historial y progreso. Señalá patrones de UI que conviene evitar porque agregan fricción o hacen más lenta la carga de datos.
